# Synapmc-Extension

Synapmc a mod extension for [JsMacros](https://modrinth.com/mod/jsmacros).

Features | |
|---|------------|
| Remote Control | Access JsMacros from outside your game or your computer|
| Package Manager | Easily share and access scripts from other players |
| Unified Folders | Create shared folders, all your scripts will always be accessible on any luncher that works with jsmacros: feather, prism, vanilla, and more. |
| Multi Language Support | Compatible with all current language extentions, plus comes bundled with Lua, Python and Ruby |
| Import Scripts |  Drag and drop to import multiply scripts. Export/Sync registered scripts |


|Added |
|---|
| JsMacros Community Edition Support `Minecraft versions 1.21.4 - 26.2`|
| JsMacros Reloaded Support `Minecraft versions 26.1 - 26.2`|
| New methods to expand the Api  |
| Custom Patches |

## Install as a mod not as an extension
This requires Fabric and Fabric Api.  <br>
Minecraft versions 1.20.1 - 26.2 <br>
